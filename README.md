# 🐾 VETCompASS

**VET**erinary **COMP**uter **ASS**istant — an unofficial, community-driven survival kit for students of VETUNI Brno (University of Veterinary Sciences Brno, Czech Republic).

> ⚠️ **Disclaimer:** This is not an official VETUNI application. It is a community project released under an open license.

>  **Language note:** This project is built for a Czech university, so the app's UI and content are currently primarily in **Czech**. An English version may follow. VETUNI also offers English-taught programmes (Veterinary Medicine, Veterinary Hygiene and Ecology) — international students are very welcome to use it and contribute!

## What it is

A single HTML file that works offline in any browser (phone, tablet, desktop). It brings together in one place:

- 🦴 **Anatomy & recognition drills** – 3D atlases, quizzes, games
- 📚 **Study resources** – notes & scripts, databases, citation tools
- ⚖️ **Legislation** – Czech acts, decrees, EU regulations
- 🗓️ **Student roadmap** – from the summer before year 1 to the final state exams
- 🆘 **Emergency kit** – what to do when…
- 👥 **Community** – clubs, social networks, where to meet people
- 🎮 **Gamification** – streaks, progress, favourites (all stored locally on your device)

## Profiles

Content is filtered by who you are:
- 🎓 **Student** – from freshman year to state exams
- 🔬 **Researcher** – databases, open science, FAIR data
- 🩺 **Practitioner** – clinics, chambers, legislation

## How to use

1. **Online:** via GitHub Pages (link in the repo's About section)
2. **Offline:** download `index.html` and open it in any browser – it works without internet (the links to external resources require internet)
3. **Sharing:** send the file via messenger, e-mail or USB stick – or scan the QR code in the app footer
